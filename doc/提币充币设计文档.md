在真实的交易所中，**充币（Deposit）**和**提币（Withdrawal）**是连接“区块链世界（链上）”和“交易所账本（链下/数据库）”的桥梁。

* **充币**：是**被动**的。交易所的节点监听到区块链上有一笔钱转入了你的钱包地址，系统自动给你加余额。
* **提币**：是**主动**的。用户发起请求，系统审核后，调用区块链节点接口把币转给用户。

由于我们没有运行真实的比特币/以太坊节点，我们将在 MVP 版本中**模拟**这一过程，重点实现**“账务处理”**和**“审核流程”**。

### 1. 数据库设计 (新增流水表)

我们需要一张表来记录资金进出。

请在 MySQL 中执行：

```sql
USE simple_exchange;

-- 充提流水表
CREATE TABLE `transaction` (
  `id` bigint(20) NOT NULL AUTO_INCREMENT,
  `user_id` bigint(20) NOT NULL,
  `coin` varchar(10) NOT NULL COMMENT '币种',
  `amount` decimal(36,18) NOT NULL COMMENT '数量',
  `type` varchar(20) NOT NULL COMMENT '类型: DEPOSIT(充值), WITHDRAW(提现)',
  `status` varchar(20) NOT NULL COMMENT '状态: PENDING(审核中), SUCCESS(成功), FAILED(失败)',
  `address` varchar(100) DEFAULT NULL COMMENT '提币地址',
  `tx_hash` varchar(100) DEFAULT NULL COMMENT '链上交易哈希(唯一键，防重充)',
  `create_time` datetime DEFAULT CURRENT_TIMESTAMP,
  `update_time` datetime DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_tx_hash` (`tx_hash`) COMMENT '防止同一笔链上交易重复入账'
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='资产流水表';

```

### 3. 功能测试流程

你可以使用 Postman 或 cURL 按顺序测试以下场景。

#### 场景一：充值 (Mock)

用户 3 注册了，现在给他充 1000 USDT。

```bash
# 充值
curl -X POST "http://localhost:8080/api/asset/deposit" \
     -d "userId=3" \
     -d "coin=USDT" \
     -d "amount=1000"

```

* **结果**：数据库 `wallet` 表中 User 3 有了 1000 USDT。`transaction` 表多了一条 DEPOSIT 记录。

#### 场景二：提现 - 审核通过

用户 3 想要提走 100 USDT。

**1. 申请提现**

```bash
curl -X POST "http://localhost:8080/api/asset/withdraw" \
     -d "userId=3" \
     -d "coin=USDT" \
     -d "amount=100" \
     -d "address=TXj7...UserAddress"

```

* **结果**：User 3 的余额变为 900 USDT（钱直接扣了）。`transaction` 表多了一条 WITHDRAW 记录，状态为 **PENDING**。

**2. 管理员审核通过**
（假设上一步返回的 txId 是 5）

```bash
curl -X POST "http://localhost:8080/api/asset/audit" \
     -d "txId=5" \
     -d "pass=true"

```

* **结果**：User 3 余额保持 900。流水状态变为 **SUCCESS**。这代表钱已经发到链上了。

#### 场景三：提现 - 审核拒绝（退款）

用户 3 再次申请提走 500 USDT。

**1. 申请提现**

```bash
curl -X POST "http://localhost:8080/api/asset/withdraw" \
     -d "userId=3" \
     -d "coin=USDT" \
     -d "amount=500" \
     -d "address=BadAddress..."

```

* **结果**：User 3 余额变为 400 (900 - 500)。

**2. 管理员拒绝**
（假设 txId 是 6）

```bash
curl -X POST "http://localhost:8080/api/asset/audit" \
     -d "txId=6" \
     -d "pass=false"

```

* **结果**：
* 流水状态变为 **FAILED**。
* **关键点**：User 3 的余额自动变回 **900** (400 + 500)，实现了退款逻辑。

### 总结

现在你的简易交易所已经具备了完整的资金闭环：

1. **进 (Deposit)**：通过 `/api/asset/deposit` 模拟资金入账。
2. **换 (Trade)**：通过 `/api/order` 进行买卖交易。
3. **出 (Withdraw)**：通过 `/api/asset/withdraw` 申请，并经过人工审核后出账。
